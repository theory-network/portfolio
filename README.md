# Theory Network Portfolio

The public site for Theory Network LLC: a company landing page, a portfolio of two projects, and freelance services.

## What's on the site

- **Home:** a one-line tagline, a short description of Theory Network, and an animated network / digital-pulse graphic.
- **Portfolio**
  - **Nexus:** feature highlights plus "coming soon" screenshots from the prototype.
  - **Firefly:** the original Firefly landing page, ported to modern Angular and led by the demo video.
- **Services:** freelance offerings such as code modernization and AI integration. Contact is through a Cal.com booking link or email.
- **About:** Theory Network LLC and its history.

The site launches on andredavcev.com and moves to theorynetwork.com once that domain is recovered.

## Stack

- **Monorepo:** Nx, with npm workspaces.
- **Host:** `portfolio-web`, from Nx's React module federation template (Vite, TanStack Router).
- **Firefly page:** an Angular remote (`portfolio-firefly`) loaded into the React host.
- **UI:** shadcn, generated by `@aws/nx-plugin` and themed from the logo colors.
- **SEO:** static HTML prerendered at build time; there is no server.
- **Hosting:** S3 and CloudFront, deployed with Terraform through `@aws/nx-plugin`.
- **Analytics:** Plausible (cookie-free).
- **Tooling:** Vitest (unit tests), ESLint, Prettier (formatting, via `nx format`), Playwright (end-to-end), and husky with git-secrets as a pre-commit hook.

## Getting started

```sh
npm install                                  # also activates the git hooks
npx nx dev portfolio-web                     # http://127.0.0.1:4200
npx nx run-many -t lint test build           # what CI should run
npx playwright install chromium              # once, before the first e2e run
npx nx e2e portfolio-web -- --project=chromium
```

## Status

Early setup. `portfolio-web` is a placeholder home page with no remotes yet, and `packages/ui` holds only the shared theme and a `Badge`. The AWS infrastructure, the Firefly remote, the brand palette and the real pages are still to come.
